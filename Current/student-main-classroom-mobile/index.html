Main Room Mobile v9b — volunteer popup flow (prototype · debug controls outside the phone)

One interactive phone. This prototype includes: Main Room Mobile · one Chat surface (Hidden / Compact / Expanded) · contextual footer (Chat composer · Camera/Mic during demonstration) · rail sheets (Timeline / Participants) · activity timer + automatic Done · demo visual states · Carousel placeholder · volunteer popup flow. Drag the self-view to move it; release near a left/right edge to collapse (camera stays on) and tap the collapsed tab to reopen it. Tap the muted mic for the teacher-controlled tooltip. Compact chat messages fade after a few seconds; expand chat for scrollable history. Not in this base: Practice Rooms routing / camera-mic enforcement / waiting / Solo / report, and final Carousel artwork.
