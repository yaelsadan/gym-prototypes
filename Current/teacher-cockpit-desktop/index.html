v25 — alignment cleanup

  • Running statuses moved into the Instruction header row. They were a separate row sitting right on the section hairline, which is what made it look broken. Now the row reads INSTRUCTION on the left and TIP ready · Broadcasting… · Round 1 · Student 2 on the right, as flat metadata — a small dot plus text, no pill, no chip, no button styling. Green dot + green text for TIP ready; yellow for Broadcasting and the active timer. The divider belongs to the section, so it sits above the whole row and can never cross the text. No extra row, no extra height, and the Rooms panel still has no internal scroll — the status strip truncates with an ellipsis rather than crowding the label.
  • Header clocks share one baseline. The clocks were nested inside their own .tc-timers wrapper, which is why they drifted off the line. They are now direct children of a single flex row with align-items:center, and ON AIR, 16:42, Rooms 07:30 and the HELPER indicator all share the same 30px height, line-height:1 and vertical alignment. The two clocks also share a font size and tabular numerals, so their digits land on the exact same baseline. Rooms 07:30 stays primary while rooms are active and 16:42 stays secondary; no pills, no backgrounds, no decorative dots, and the header is the same one row at the same height.
  • HELPER label centred — root cause fixed. .tc-role.helper (specificity 0,2,0) was still applying a yellow fill from an older block, while a newer .tc-role rule (0,1,0) stripped its padding to zero — so the label was jammed inside a zero-padding holder. It is now a subtle yellow holder with symmetric padding, inline-flex + align-items:center + justify-content:center + line-height:1, and no asymmetric margin. It reads as a mode indicator, not a CTA.
  • Unchanged: helper sees the teacher feed, helper can Edit / Reset their own layout, Switch to Teacher stays inside the Helper Mode panel header, helper cannot control any teacher action, hover-only recipe tooltip, Rooms panel no-scroll, Start → Pause → Resume → Reset, Operation Grandma’s automatic internal flow, Visual tools behaviour, four equal-width control buttons, mic/camera overlay, Operation Grandma naming. No new UI concepts.
