Default Classroom Self-view — v1 (corrected working base)

The default classroom self-view, rebuilt on the real working bases: Chat System v1 (overlay + sheet + keyboard + rail, ported verbatim) and Classroom Chrome v1 (header Active/Faded, REC, exit gated on Active). The small video is the self-view only. Camera is the student's quick control; the mic is shown muted (teacher-controlled), not a free student toggle. Collapse/expand and drag stay available; collapsed ≠ camera off. Demonstration is a separate layout state: the selected student is pinned beside the teacher in a split view and their own self-view folds.

Chat & chrome here are the real Chat v1 / Chrome v1 systems, not placeholders. The previous followed-message treatment (yellow left rule + sparkle) now marks Helper messages.
